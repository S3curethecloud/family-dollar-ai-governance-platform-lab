# Phase 7 Interview Questions — SOPs, Runbooks & Support Handoff

## Likely Questions

1. How would you transition an AI application from prototype to IT support?
2. What belongs in an AI runbook?
3. How would you document rollback for an AI workflow?
4. How would support troubleshoot a failed agent workflow?
5. What evidence should be included in a support handoff?
6. How would you handle an AI incident involving customer data?
7. How would you define severity for AI workflow incidents?
8. How would prompt versioning work in a governed AI platform?
9. How would model promotion work across dev, test, and production?
10. How would you remain the architectural escalation owner after handoff?

## Strong Answer Pattern

A strong answer should include:

- Intake and risk-tier evidence
- Architecture ownership
- Data contracts
- Policy gates
- Observability dashboard
- Workflow traces
- Prompt/model versions
- Rollback path
- Incident escalation path
- Support handoff checklist
- Post-implementation review

## Interview Talk Track

"I treat AI support handoff as a controlled transition, not a throw-over-the-wall event. Before IT accepts ownership, the workflow must have intake evidence, risk tiering, architecture documentation, data contracts, policy gates, traceability, cost controls, rollback instructions, incident escalation, prompt/model version records, and a support checklist. I remain the architectural escalation owner for governance, integration, and risk decisions."
