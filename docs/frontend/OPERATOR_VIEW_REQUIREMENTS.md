
Operator View Requirements
Purpose

Define what operators, platform teams, and governance reviewers need from the command center.

Operator Questions
Which workflow is being reviewed?
Which system does it touch?
Which policy gate applies?
Which approval is required?
Which risk tier was assigned?
Which evidence supports the decision?
Which runbook applies?
What is the rollback or support path?
Required Operator Surface Elements
Workflow detail cards
Risk tier evidence
Approval state
Policy gate decision
Enterprise system/API contract ownership
Observability signals
Support handoff links
Runbook references
Operator UX Principle
Operators need traceability from workflow to risk, policy, approval, evidence, and support path.
