
Mobile Responsive Requirements
Purpose

Define mobile and small-screen expectations for the AI Governance Command Center.

Mobile Success Criteria
No horizontal page overflow
Cards fit viewport
Tables or dense lists wrap or scroll internally
Primary status summary remains visible
Navigation remains usable
Approval states remain legible
Risk labels remain readable
Command center remains useful for quick executive review
Responsive Review Targets
Dashboard summary cards
Agent workflow cards
Risk tier cards
Policy gate decision cards
API contract lists
Observability/cost panels
Runbook/support panels
Mobile Boundary
Mobile hardening should not change backend behavior, policy decisions, or governance logic.
